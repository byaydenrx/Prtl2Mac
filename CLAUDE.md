# Prtl2Mac: start here

Follow `WORKFLOW.md`. At the start of a session run `sh scripts/resume.sh`,
then continue with the next action in `SESSION_HANDOFF.md` (or the top
unblocked task in `TASKS.md`). Keep `TASKS.md`, `PROJECT_STATE.md` and
`SESSION_HANDOFF.md` current as you work, and commit and push them with the
code. Work in your own git worktree; never edit another session's checkout.
