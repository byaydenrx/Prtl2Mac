# Roadmap (owner's wishlist, 2026-10-18)

Rule over everything: keep the game as close to the original as possible.
New options go inside the existing Settings screens (no extra buttons on the
main or pause menu). Launcher features come later.

## Settings (inside the normal options)
- Refresh rate / frame limit as a slider like FOV (120 Hz and higher).
- FOV adjustable from the original up to 110.
- V-sync: one-click toggle.
- Resolution, frame limit, optional anti-aliasing, anisotropic filtering.
- Priority: smooth frame pacing and sharp image over flashy effects; Metal tuning.
- Enhanced graphics: one toggle (Original / Enhanced presets). Slightly
  better shadows, ambient occlusion, texture filtering, reflections where
  feasible, optional colour grading. Art direction unchanged.
- Subtitles: a sub-section to click into (size, colour, background).
- Scalable UI, configurable input, quality-of-life fixes.
- Optional dev console and movement stats.

## Game modes
- Co-op campaign.
- Speedrun / challenge mode: built-in timer and splits, chapter and
  single-chamber select, quick restart and checkpoint restart, practice mode
  with configurable checkpoints.
- Photo mode and free camera.

## Content
- Custom maps and campaigns with saved progress; load any `.bsp`.
- Browse and launch local community maps from the in-game menu (local
  first, Workshop later).
- Native map editor.
- Mod manager: profiles, install / enable / disable / order mods without
  replacing files, load order, dependency checks, compatibility warnings,
  one-click rollback.

## Infrastructure
- Save data that stays compatible across updates.
- One-click updates.
- Crash reports and logs sent somewhere we can see them (GitHub issues).
