# Intended solutions, per map

One file per map, `<map>.md`, written or corrected by the owner (a
walkthrough is fine as a source; keep it in your own words). A session
proving a map reads it instead of working the solution out from entity
dumps, which is the most expensive part of proving a map. None exist yet
(2026-10-21).

Template:

```markdown
# sp_a2_trust_fling
Solution:
1. ...
2. ...
Surfaces that must take portals:
Exit opens when:
Shortcuts players use (not the intended route):
Route: scripts/routes/sp_a2_trust_fling.txt (none yet)
```
